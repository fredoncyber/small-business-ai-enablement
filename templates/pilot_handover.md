# Coordinator handover — blank checklist

- [ ] Permission and approved AI tool confirmed.
- [ ] Explain what the toolkit does and does not do.
- [ ] Identify a low-risk task and remove sensitive details.
- [ ] Open the browser toolkit and select Operations.
- [ ] Enter approved notes and build the prompt.
- [ ] Copy into approved AI tool; inspect output against original notes.
- [ ] Mark unknowns, correct errors and obtain reviewer approval.
- [ ] Clear browser inputs; retain or delete records under agreed policy.
- [ ] Complete a new task independently, without coaching.
- [ ] Record time including review, rubric scores, questions and whether independent use succeeded privately.

Participant feedback prompts: What was useful? What was difficult? Would you use it independently? What should change? Request separate consent for public quotations. Do not commit completed forms.
